Capabilities

Everything a Modern Plan Needs

Powerful capabilities with AI orchestration — all self-hosted on your infrastructure.

Kanban Board

Drag cards across status columns with color-coded priority bars, assignee avatars, due dates, tags, and per-card progress fills.

Gantt Timeline

A day-by-day Gantt chart with task bars, weekend shading, a today marker, and assignee metadata for accurate scheduling.

List View

A sortable data table with status pills, priority pills, assignees, and inline progress bars for quick triage across the plan.

AI Assist

One-click AI Assist helps draft and refine tasks directly inside the planner without leaving the board.

Rich Task Properties

Priorities from low to urgent, assignees, tags, start and end dates, dependencies, and progress tracked on every card.

Import & Export

Export the entire plan as a portable JSON file and import it back — data is stored locally in your browser, fully sovereign.
