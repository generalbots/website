Report a vulnerability

Send a private report before disclosing publicly. Include affected versions, reproduction steps and impact.

  1. Email security@pragmatismo.com.br. Ask for the current PGP fingerprint in your first message if the issue is sensitive.
  2. We acknowledge within 3 business days and triage within 10.
  3. Coordinated disclosure: 90-day embargo, extendable by agreement.

No bug bounty program

Reward budget: 0. We offer public credit only — in the hall of fame and in advisory credits.

Frequently asked questions

Why is there no forum thread for reporting?

The forum is for discussion. Reports must go to the private security mailbox so details stay embargoed until a fix is available.

How do I verify an advisory?

Check the canonical URL and the published signature. The same advisory is available in CSAF and OSV form.
