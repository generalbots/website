Agent mode works inside an isolated virtual machine. Allow a single action, grant access within the conversation, or deny it. You can revoke access, and actions outside the virtual machine require separate approval.

Frequently asked questions

Do I need an internet connection?

Once a compatible local model and its components are set up, local inference can run offline. Hosted engines and web research need a connection.

Is my data used to train a model?

With a local model, inference uses prompts on your computer. For an external engine, the provider’s policy applies. Lite shows the engine’s destination before you send data.

Can the agent change something without my knowledge?

The agent operates in an isolated virtual machine. Permission cards control its actions, and the conversation shows the steps it takes.

Which computers are supported?

This edition targets Windows 11. Agent mode uses WSL2. Check the setup wizard for local-model hardware requirements.

How much does it cost?

The application is free and MIT-licensed. Hosted engines and subscriptions follow the provider’s pricing and terms.
