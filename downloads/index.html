Install

One line installs it

The command fetches the newest build, unpacks it and runs the per-user installer. Nothing is written outside your home directory, and no daemon is registered.

bash 
curl -fL https://github.com/generalbots/generalbots/releases/latest/download/generalbots-linux-x86_64.tar.gz | tar -xz && ./generalbots-*-linux-x86_64/install.sh
powershell 
iwr https://github.com/generalbots/generalbots/releases/latest/download/generalbots.exe -OutFile "$env:TEMP\gb-setup.exe"; & "$env:TEMP\gb-setup.exe"

On first start the wizard asks for a display name, a model provider and an API key, then provisions the services.

Integrity

Check what you downloaded

Each release publishes a SHA-256 manifest next to the tarball. One command, no keys, no extra tooling.

The manifest covers both the stable alias and the versioned tarball; --ignore-missing skips whichever you did not download.

bash 
BASE=https://github.com/generalbots/generalbots/releases/latest/download
curl -fLO "$BASE/SHA256SUMS-linux"
sha256sum -c SHA256SUMS-linux --ignore-missing

# generalbots-linux-x86_64.tar.gz: OK
Requirements

What it needs

The download is small — the wizard fetches the services on first run.

Linux x86_64

Ubuntu 22.04+ or an equivalent with GTK / WebKitGTK 4.1. libwebkit2gtk-4.1-0 is the only required library.

Windows x64

Windows 10 / 11 with the bundled WebView2 runtime. The installer is published on a best-effort basis.

Disk and network

About 4 GB free for the stack, plus internet on first run — or an installers/ bundle.

Privileges and GPU

None needed — everything stays in your home directory. A GPU is optional.

Need a pinned version?

Versioned assets embed the tag in the filename; the tag-free alias exists only on /latest/. Replace v6.7.0 with a tag that has actually been published.

bash 
TAG=v6.7.0-desktop.7
curl -fL https://github.com/generalbots/generalbots/releases/download/$TAG/generalbots-$TAG-linux-x86_64.tar.gz | tar -xz
cd generalbots-$TAG-linux-x86_64 && ./install.sh

Questions

Before you install

Do I need root?

No. install.sh writes to ~/.local/opt/general-bots, links a launcher into ~/.local/bin and registers a desktop entry. Pass a different prefix as the first argument if you want another location.

Where does my data live?

Everything runtime-related stays in ~/.local/share/generalbots: the service stack, the workspace and the logs. Point BOTSERVER_STACK_PATH at another directory to run an isolated stack.

Can I install without internet access?

Yes. Put the component archives in an installers/ directory next to start.sh before the first run — when that directory has files, the wizard downloads nothing.

Which services get installed?

PostgreSQL, Valkey, MinIO, Qdrant, Vault, Zitadel and llama.cpp. Progress is reported per component and the full log is written to ~/.local/share/generalbots/logs.

Why does a download link return 404?

The link resolves to the newest release that carries the build. If nothing resolves, no release has that file yet — pin a published tag or build from source.

Is there a macOS build?

Not yet published. Build from source, or run the same software as a managed instance instead.

How do I upgrade?

Download the newer tarball and run its installer again. The runtime state in ~/.local/share/generalbots survives reinstalls.

Rather not run it yourself?

The desktop build and the hosted deployment run the same software. Pick a hosting partner or self-host the server edition.
