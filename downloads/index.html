System requirements

Windows

  • Windows 10 (1903+) or Windows 11, 64-bit
  • 4 GB RAM minimum, 8 GB recommended
  • 500 MB free disk space
  • Internet connection for first-run setup

Linux

  • Ubuntu 22.04+ / Debian 12+ / Fedora 39+ (64-bit)
  • 4 GB RAM minimum, 8 GB recommended
  • 500 MB free disk space
  • glibc 2.35+, libwebkit2gtk-4.1

All platforms

  • Modern browser engine (Chromium/WebKit) for the UI
  • PostgreSQL 14+ for the server (bundled in installer)
  • Optional GPU for local LLM inference
  • Admin rights for first install only

Quick start

Windows
  1. Run the installer and follow the wizard.
  2. Launch "General Bots" from the Start menu.
  3. Complete the 2-step setup wizard.
  4. Open http://localhost:3000 to chat.
Linux
  1. chmod +x the AppImage, or install the .deb package.
  2. Launch from your applications menu.
  3. Complete the 2-step setup wizard.
  4. Open http://localhost:3000 to chat.
